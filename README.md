# Tokyo Real Estate Market Intelligence 🏢🇯🇵

## 📌 Project Overview
This project provides a data-driven analysis of the Tokyo Real Estate market using Python and Excel. The goal is to help investors identify high-value locations and understand the factors influencing property prices, such as building age and proximity to transit hubs.

## 🛠️ Tech Stack & Methodology
* **Data Cleaning:** Performed initial cleaning in **Excel** and advanced transformation using **Python (Pandas)**.
* **Analysis:** Statistical evaluation of 50+ premium property records.
* **Visualizations:** Created using **Matplotlib** to identify market trends.
* **Core Skills:** Data Wrangling, Feature Engineering, and Strategic Business Insight generation.

### Final Takeaways:
* **Capital Appreciation:** Focus on **Chiyoda** for the highest long-term value.
* **Renovation Strategy:** Properties older than **20 years** are ideal for "Flip" strategies (Value Buy).
* **Rental Yield:** Ensure properties are within **500m of a station** to maintain high occupancy and stable income.
